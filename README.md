Halo, saya **Abdul Haris Rosa**. Saya menekuni **Teknik Informatika di Universitas Muhadi Setiabudi** serta beraktivitas sebagai **tenaga pengajar dan teknisi (Toolman) TKJ di SMK Bhakti Praja Talang**.
